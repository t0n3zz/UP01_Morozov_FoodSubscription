## Описание работы

WPF-приложение для учёта подписок пользователей на продуктовые наборы (боксы)
с подключённой базой данных Microsoft SQL Server.

Реализовано:

* авторизация и регистрация пользователей с разграничением ролей
  (**Пользователь** и **Администратор**);
* хэширование паролей алгоритмом SHA-256 — открытые пароли в базе не хранятся;
* капча после трёх неверных попыток входа (генерация картинки и её проверка);
* смена пароля с проверкой текущих учётных данных;
* страница пользователя: просмотр своих подписок, поиск, фильтрация по категории,
  сортировка;
* страница администратора: всё перечисленное плюс добавление, редактирование
  и удаление записей трёх таблиц, диаграмма расходов и экспорт отчётов
  в `.docx`, `.pdf` и `.xlsx`;
* каскадное удаление связанных данных;
* подтверждение выхода из приложения и удаления записей;
* проверки формата вводимых данных, маски ввода и ограничения диапазонов;
* плейсхолдеры и всплывающие подсказки у всех элементов ввода;
* динамический заголовок каждой страницы;
* два словаря стилей (фирменный и собственный) с переключением темы;
  выбранная тема сохраняется между запусками приложения.

## База данных

СУБД: **Microsoft SQL Server**. База данных `DB_Morozov_FoodSubscription`, три таблицы:

| Таблица        | Назначение                        | Поля |
|----------------|-----------------------------------|------|
| `User`         | пользователи сервиса              | ID, Login, Password, Role, FIO, Photo |
| `Category`     | категории продуктовых наборов     | ID, Name |
| `Subscription` | оформленные подписки пользователей | ID, CategoryID, UserID, Date, Name, Num, Price |

Связи: `Subscription.UserID → User.ID` и `Subscription.CategoryID → Category.ID`,
обе с правилом `ON DELETE CASCADE` — удаление пользователя или категории
каскадно удаляет связанные подписки.

## Запуск

1. Выполнить скрипт `db/schema.sql` в Microsoft SQL Server Management Studio.
2. Открыть `UP01_Morozov_FoodSubscription.sln` в Visual Studio 2019/2022.
3. Восстановить пакеты NuGet (Entity Framework 6, Microsoft.Office.Interop.Word и Excel).
4. При необходимости изменить имя сервера в строке подключения в `App.config`
   (например, на `.\SQLEXPRESS` или `localhost`).
5. Запустить приложение (F5).
